# Windmill 原生 Agent 隔离对照 · 事前判据

基于 #5 bb55c843，比较 #12 f5b4df8 的同一产品题。引擎固定 windmill-labs/windmill v1.882.0，源码 28985a122cc303200bb36c5c67037f5f2157299c。优先使用 CE 原生 aiagent、引用脚本或 inline 工具与工作流，以固定产品任务/操作引用访问单独产品账。先在真实 CE、独立 PG 及受控协议模型上建立无故障基线。原生工具可选后台执行时优先查验该路径。下游的异步 HTTP 受理、权威效果和模拟费用分别独立留账。没有期间生产权限或实际供应商费用。

|工况|共同可观测判据|
|---|---|
|基线、已知且有权的可兼容重入|工具 HTTP POST/效果/费用/正式交付各 1；模型请求 2；第 2 次含第 1 次实际模型产生的 call ID 和唯一权威回执或能由受控入口开出的同一回执引用。记录基线与中断结果。|
|故障定位|控制器先见独立受理，效果费用为 0，驱动后台完成再见效果、费用各 1；证明工具结果未进引擎或正式产品账，才 SIGKILL 持有任务的 Worker。新进程读取已提交运行；必须区分 Agent 和工具进程，禁止把重跑整个实验当成恢复。|
|未知、取消迟到|暂不可查时上述工具/效果/费均只 1，held=3，spent=0，模型总共 1、交付 0。记录未知再取消，开放查单并重复通知，最终 held=0/spent=1，工具、模型、交付均不再增长。|
|旧数据、错配、载荷|不支持版本保存并隔离；错误 ID 在模型/交付前拒绝；独有权限载荷在最终解码引擎记录零出现，工具/模型私有端有阳性对照。逐项报告未测，原生存储原始 ID 与受限正文分别列计。|
|运维、许可、成本|真实版本/API、镜像摘要、源码与许可、部署拓扑、适配配置及公共代码、能力登记点、操作层查单和恢复权责独立计。分别报告镜像、运行、样本、独立审查的实状。|

若真实原生最小无故障路径不能启动，先经版本/许可、配置、部署来源逐点定位；真实限制只约束该路径。若无对外公开的可恢复续接，优先验证最小外部账/查单或回执引用适配；需要重写整个 Agent Loop 的方案独列成本。未知、取消、错配不自动算通过，源码不能替代运行。能直接裁决基本符合的切片先归档；下一阶段 IAM、真实付费、完整宿主、生产、W0/MVP 和合并均不在本次。为保证审查可复核，留存官方源入口、实际命令、完整日志和原始逐笔记录（合成数据）。
