# Agno AgentOS 工具回合对照实验

实验从 #5 bb55c843b8dd2e9ad646e982a38cda350b3df952 单独分支。按 #7 9d61564347dbea5ada09678c1aa8b9d16f36a2df 和 #12 f5b4df8f70e3033e52fc8a8906f8f13eeb29b2b1 的同题判据，对固定 Agno 3.2.0（3bfc84113fdd80c1522ef7bafa80721ce79fdf62，Apache-2.0）做独立合成实验。所有流量仅到隔离测试服务。没有生产接入或合并授权。

使用真实 AgentOS HTTP、开源 OpenAIChat 适配器、标准 PostgreSQL 会话，动态模型调用号由独立 HTTP 模型产生。模型在第一轮要求外部执行工具，框架持久化 paused 状态。独立 HTTP 工作进程接收一次、返回 202，控制器让服务端在独立账上留下效果、唯一收据与一笔模拟费，确认产品尚无终局结果后向原 AgentOS 及执行/对账 worker 发 SIGKILL。新 PID 通过 HTTP 读旧 session/run/requirement，产品按稳定操作号向收端核实，使用原调用 ID 和收据。独立记录模型原始请求、收端发送/效果/每次计费/交付，披露 AgentOS 内建部分、产品与业务方定制，以及框架在此模型中是否承担调度职责。

| 场景 | 事前判断 |
| --- | --- |
| 已知、有权、可读的记录版本 | 同一框架 run 与 session，第二模型请求的工具 ID 及结果等于独立收端证据。工具、效果、费用、交付各一，模型两次。 |
| 暂不可查 | 工具/效果/费用各一，模型一、交付零，产品 held=3/spent=0。保留状态，可重复核对，不重发。 |
| 已取消、迟到、重复通知 | 先观察未知，再取消、开放查证、两次核对仅结算一次。held=0/spent=1，模型/工具/交付零增量。 |
| 旧产品版本不兼容 | 可核账但隔离旧状态，不推进模型、工具和交付。固定 Agno 版本，不冒充真实框架跨版本。 |
| 回填错误的工具 ID、重复完成 | 提交给受治理入口的不匹配结果被拒绝，零模型及交付增量；有权真实回填已完成后再触发不能重复收取费用、交付或开启新模型运行。 |
| 撤权 | 旧状态读回后、向模型实际发送前撤权，受保护后续模型和交付零新增，已发生的效果费用仍保留。说明哪些出口与真实资源方尚未验证。 |
| 载荷与持久边界 | 对读回的产品行、AgentOS 会话及独立模型实际请求扫描合成敏感标记和调用 ID，区分必需正文与仅引用。没有另加调度器就没有对应的调度历史，须披露平台本身写入正文的位置。 |

另核 AgentOS 工作流 HTTP 与直接入口能否在同一管控规则下复用能力，若未验证则单列。实验须记录版本、提交、进程号、前后状态、独立收端计数、原始断言及 CI 链接。收端可复用 #12 的中立夹具，B 的工作流/Agent/派发不沿用。发布和产品路径之外的实验支撑计数分开披露。先冻结本文件，再提交代码，独立审查后归档。
