# 明镜全机构知识库需求文档

**项目方已确认需求，确认版本为 [43b6f23](https://github.com/zhuquanwei111/mingjing---agent/blob/43b6f2384bd8d9afc54ec0f0bda26fb9117a1d25/docs/requirements/knowledge-base-requirements.md)。** 员工遇到一件事，应能用平时的说法找到自己有权使用的资料，回到原件核实，并把正确的版本交给下一位同事。七个范围覆盖全机构。下文的岗位是工作分工，例子中的项目、许可和日期条件均为评审用设定，实际负责人和授权以明镜业务记录为准。

## 七个业务范围里，谁拿什么资料办什么事

### 1. 机构制度与岗位协作

行政、人事和制度负责人发布岗位手册、办事流程及新旧规定的生效日期。值班人和接班人留下当班记录。员工办报销、主管处理例外、场务换班时，需要分清通用规定、一次批准和今天实际谁接了班。

**员工怎样验收**　“上周五垫的车费，今天才填，用哪版？群里说不用签字了。”如果规定按乘车日划分，员工能打开上周五适用的条款，看到仍要谁确认、是否可以线上签。再问“今晚棚二谁接？”能查到棚二这次交接；尚无人确认时，看到待接状态和当班联系人。别的棚有人接班，棚二仍应显示待接。

### 2. 主播经纪与人才培养

经纪记录培养目标和跟进结果，教练在排练后留下个人批注、练习和示范片段，培训负责人发布可用于带教的课程。经纪给同一位主播续上次的课，带教给一组新人上课，两次用到的资料和允许看的人不同。

**员工怎样验收**　“上回小乔总抢话，老师让她怎么练？今晚我陪她过一遍。”负责小乔的经纪能打开对应的批注，找出“等搭档说完再接一句”，核对上次练到哪里。追问“能给整组学吗？”时，能找到有教学许可的示范。新人用自己的身份打开，只看到班内练习；个人辅导原片、批注及其转述均不出现在课件里。

### 3. 内容创作与素材

编导写选题、脚本和分镜，拍摄与剪辑人员留下排练片、粗剪、定稿和审片意见。编导核对镜头，商务和带教按用途取片时，需要找对项目和剪辑版本，还要能查到出镜、音乐、渠道等许可。

**员工怎样验收**　“她说‘切近点’时真的拍到手了吗？给我看定稿那一下。”员工点开的是定稿中拍到手的画面，能往前回看台词与切镜之间的几秒；粗剪的时间点单独标明。只有文字稿时，只能指出台词出现在哪里，并说明画面还要找谁核。问“这十秒能拿去投广告吗？”时，有权的经办人能查到对应许可及适用渠道。

### 4. 直播与制作运营

运营留场次计划、现场观察、复盘和后续改进项，制作和妆造留场地说明、定妆照及确认意见。主播、跟播运营和妆造师需要把上场决定带到下一场，也要分清已经定过的造型和明天实际可约的时段。

**员工怎样验收**　“上回说先亮成品，昨晚她改了没？”运营能从上次的改进项点到昨晚首次展示成品的画面。只有整场均值时，开场有没有掉人留待分时数据核实。再问“明天下午照这套妆，去掉头饰，先看看谁有空”，能找到对应定妆图，保留去头饰的要求，按排班方当前记录报空档和查询时间。妆造师那边没有新增预约；排班暂时查不到时仍能先交图。

### 5. 商务、客户与项目交付

商务留客户需求、报价和谈判稿，合同负责人保管签成的条款和补充单，项目交付人留送审版本、客户确认和收件记录。商务要能解释上次最终交了什么，也要知道给下一位客户可以展示到哪一步。

**员工怎样验收**　“上回嫌贵，最后到底少交了啥？我想给新客户举个例子。”原项目商务能从签成的补充单核到删减的交付项，看到哪些只在谈判稿里提过。给新客户准备的材料只含获准展示的内容。问“客户收到了吗？”时，只有本版草稿和旧版的“OK”，就答“这版没有交件记录”；已交件但收件处还查不到，就答“已发出，送达待核”；指定收件处已有本版而客户尚未确认，则答“已送达，待客户确认”。每一步都能核对版本和对象。

### 6. 经营、财务与合规

经营人员维护指标定义和变更说明，财务留下对账表、扣项与到账依据，合同或合规负责人维护合同模板、授权期限及一次例外。项目人员需要查清差额，主管需要知道上次的批准这次还能不能用。

**员工怎样验收**　“这单怎么少了三千？”举例，合同 3.6 万元、已确认扣项 3,000 元、实收 33,000 元。有权核账的人能从这三笔数各自打开同一项目的条款或流水行，看清单位，算出余额为零。查不到最新流水时，已核的两项仍可见，余额标作待核。“去年的活动用过这首歌，今年也行吧？”能查清上次许可的活动、用途和期限；新活动还缺哪项许可、由谁核实，都说得清楚。

### 7. 行业研究与组织经验

研究和运营人员收集外部报道、平台变更和同行案例。一线团队记下尝试、失败、适用条件及后续观察，岗位负责人据此审核手册。员工需要判断某个建议是别人讲过、自己团队试过，还是机构已经决定照做。

**员工怎样验收**　“听说开头别自我介绍，咱们也这么定了？换班后试过吗？”员工能分别打开外部文章、试过的场次和当前手册，看到首次合作场适用哪条。换班后缺少记录，就显示已知结果到哪一场为止。新人能据此为自己的场次备稿，负责人也能回查写进手册的依据。

| 青年力量 | 据飞书具名客户案例，签约与媒介人员登记达人信息，运营更新其权益，商务接到需求后匹配人选。财务按项目表单、财务表单和银行流水核账，订单与流水变化时需随之更新。[飞书·青年力量客户案例](https://www.feishu.cn/customers/youthpower) | 匹配经验可以复用；今天的权益和到账金额须能核到负责方的当期记录。员工应看得到数字的项目、单位、日期及缺哪一项依据，见范围 5、6。 |

## 一条片尾，从编导交给商务，再进新人课

用同一个虚构项目贯穿评审。编导给“晴禾”春季项目剪了蓝背景片尾，有粗剪和定稿。项目许可允许晴禾在约定日期内用自有账号自然发布指定的客户版。另有一份教学许可，允许本期新人班在课内观看去掉客户标识、换过音乐的教学片段。两份许可各有对象、版本、用途和有效期。

### 同一份资料到了谁手里，能做什么

| 拿资料的人 | 这次能看到或使用什么 | 换一个用途怎么办 |
| --- | --- | --- |
| 编导、剪辑 | 在本项目内看脚本、粗剪、定稿和审片意见，修订片尾，把带版本的交付件交给项目商务。 | 另剪广告或教学片先核用途和素材许可。编导能改画面，扩大客户使用范围由合同或授权负责人确认。 |
| 合同或授权负责人、项目商务 | 前者核原条款并记录适用对象、日期和渠道；后者看办理本项目所需的许可和指定客户版，按获准用途交给晴禾。 | 换客户、转付费投放或上大屏须另核。商务查条款、预览、实际交件分别留结果。 |
| 带教经纪（本课教案负责人） | 看有教学许可的片段及其课内使用范围，编练习、标时间点、发布教案。 | 看不到客户合同、报价和未授权原片。换课程或想导出素材，先核新增用途。 |
| 新人学员、客户收件人 | 本期学员能在课程中观看教学片段并完成练习；晴禾指定收件人能取得自己的获准客户版。 | 学员不能下载或向群外转发。其他客户拿到旧消息或链接，也看不到晴禾项目的标题、缩略图、条款和内容。 |

### 按发生顺序验收

| 员工会怎么说 | 接下来应看到什么，怎样判定办成 |
| --- | --- |
| **交件**　编导：“这条定稿给晴禾。粗剪里那首歌还没换，别拿错。”商务：“先给我看看，客户还没要。” | 商务打开的片尾能对上定稿和使用说明。此时客户收件处没有新增交付。经办人随后按许可明确交给指定收件人，收件人打开的是同一客户版；商务能查到交给谁、哪一版，以及对方是否已确认。 |
| **换用途**　商务：“他们说‘投一下’，是自己账号发，还是要买推广？换个客户也想看看。” | 能从许可查到晴禾自然发布的起止日。付费推广、活动大屏或换客户都要另核；这些请求不会把片段送出去。另一个客户拿着转来的链接重开，看不到项目资料。 |
| **商务交给带教**　带教：“这段正好教新人接镜头，你把能上课的那版给我吧。” | 项目商务按独立教学许可，把同一片尾的教学版入口交给本课带教。带教从自己的收件处打开，核对片中已去掉客户标识、换过音乐，核对版本、允许使用的班级和有效期，再确认收件。交接记录写明双方和教学版，附件中没有客户交付件或合同。 |
| **进课堂**　学员：“老师说的那个镜头在哪儿？我在课里点哪个？” | 带教将收到的教学版编入教案，标明画面的位置和练习。学员从课里打开就能做练习；换成没有这门课权限的员工，同一链接只见无权访问。教案里找不到客户版附件、底价及私教批注。 |
| **按当时的约定回查**　商务：“刚更正了自然发布的起始日。昨天交的是哪版？周五还能发吗？” | 合同负责人把更正依据和适用日期记清。经办人能回查昨天实际交付的版本、时间及当时依据，再按更正后的许可单独判断周五的使用。若新日期影响已交件，原交付记录仍在，商务能找到该收件人并记录处理结果；一次例外有自己的对象和期限。 |
| **改原件，也改教案**　学员：“编导换过片尾了，讲义上那一秒还是远景，手呢？” | 编导发布修订版原片，标出手部镜头在新旧两版里的位置。资料维护人列出引用旧片的教案、练习和受控链接，通知各自负责人。**引用它的教案由本课带教经纪负责改**。若只是讲义写错秒数，带教复看已获准的教学片，更正讲义和练习。若换片，新版本须有教学许可；取得许可并改好前，学员从课程入口重开只见该练习暂停及负责人。带教核对后重发，学员在标注处能看到手部镜头。带教记录改了哪节课、用的哪版；其他引用各自销项，换岗时由接任者接单。 |
| **撤回后重开**　学员：“我从上周群里的老链接点进去，还能看吗？” | 授权负责人确认撤回教学许可，资料发布负责人撤回教学版。原本有权的学员从群消息、收藏、旧回答引用或课件重开，只见“该教学片段已撤回，已停止使用”及联系带教的入口；看不到旧封面、正文、播放或下载。重开知识库里的旧对话，原先摘出的受限内容也显示撤回提示。重新搜索取不到旧摘要。班外人员仍只见无权访问。以后恢复班级读权，已撤回的片段仍打不开。 |
| **收尾**　带教：“旧讲义里也嵌过这段，谁收尾？客户那边受影响吗？” | 教案负责人检查讲义和练习，移除片段或换上另获批准的材料，再用学员身份核对。商务核对撤回涉及的版本和用途。本例只撤教学许可，晴禾的使用仍按其独立许可判断；若撤回也涉及已交客户版，商务按交付记录通知收件人。曾合法下载的副本，由经办人记录停用通知、回执和仍未确认的人。 |

再换一种撤回原因。编导通知“出镜人要求这段画面都停用”。授权负责人核实撤回覆盖原片及上述两种用途，发布负责人撤回受影响的版本，商务与带教分别停用客户版和教学版。晴禾收件人和学员各自重开旧链接，都看不到该段画面。商务仍可按权限查到曾经交过哪一版、通知了谁、谁还没回执。

判断这条链是否走完，要看商务收件处、客户收件处和学员课程里各自能打开什么。由相应岗位保留版本、交付或发布记录、旧链接重开结果，以及还待谁处理。汇总人只能查看自己获准的记录。

## 已确定的五层分类

| 分类 | 从员工一侧看，这层需要支持什么 |
| --- | --- |
| 资料原件、版本和发布 | 能找到谁发布的、当时用哪版、现在还能给谁用，以及更正或撤回要通知谁。 |
| 检索服务 | 凭项目号、岗位俗称或一句描述找到有权用的材料；遇到同名项目能分清，撤回的摘要和预览不再出现。 |
| 文档与复杂版面 | 从结论点回原页、表头、行列、脚注或补充条款，核清单位和适用条件。 |
| 音视频与图片 | 打开对应剪辑版的画面、声音或定妆图；分清哪句是原话、哪个动作确实出现、哪项只是人的判断。 |
| 中文向量与回答 | 听懂“那个蓝尾巴”“上回她说的那招”等说法，结合本轮附件和前文找出处。人改口时随之改答，有歧义时只追问缺的条件，证据不足时说明还缺什么。 |
