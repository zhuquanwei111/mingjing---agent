# 01 项目目标与非目标

## 项目目标
明镜是可持续扩展的 AI Agent 平台，而非某一业务产品或多 Agent 演示。平台提供能力契约、发现、授权、编排、状态、验证、观测、计量和版本治理；能力自身可由普通程序、固定工作流、Agent Loop、远程服务或专门执行引擎实现。

## 关键原则
1. 稳定平台边界，开放业务实现方式。
2. 确定性代码和智能判断合理分工。
3. 逻辑控制面、执行面、数据面、治理面，不强制拆分为多个微服务。
4. Task、Run、Artifact 和能力契约有明确版本及所有权。
5. 身份、权限、预算与副作用由程序强制控制。
6. 业务事实、知识证据、任务状态、模型上下文和记忆相互区分。
7. 支持不同入口复用同一能力，不要求一切 Agent 化。
8. 可扩展不等于零开发，长期可维护比一次性功能覆盖率更重要。

## 非目标
- 不在第一阶段建设完整 SaaS、复杂多租户运营后台、低代码拖拽画布或插件市场。
- 不默认实现跨组织 A2A、自组织多 Agent 网络、长期记忆或完整商业计费系统。
- 不为了架构完整而同时部署 Dapr 和 Temporal。
- 不用任何既有业务示例反向限定能力类型或 Agent 数量。

## 第一阶段成功标准
能够从一个新仓库取得可运行、可测试的最小工程，展示普通程序、可恢复异步工作流、受控 Agent Loop 三类能力在同一授权和结果契约下接入，并通过关键故障与撤权测试。
