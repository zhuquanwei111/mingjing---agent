# 08 验收矩阵与故障注入

## AT01 异构能力
一个普通程序能力可从直接 API、确定性工作流和 Agent 工具入口调用；共享实际业务实现与统一授权、operation_id、审计，不复制三套业务逻辑。新增能力无需修改 Temporal/LangGraph 核心。

## AT02 异步恢复
工作流等待外部事件时重启 Worker，重启后恢复到正确状态；重复和迟到回调不造成重复推进。

## AT03 业务写入结果未知
在业务数据库已提交、Activity 尚未报告完成的窗口注入故障；重试返回首次收据，不重复产生业务效果。没有幂等能力的外部服务应明确进入未知/人工核实，不盲重试。

## AT04 审批与撤权
未经授权的主体不能审批；审批通过后、真正写入前撤权，执行必须拒绝。历史授权快照不得覆盖实时权限。

## AT05 取消和补偿
取消请求能够阻止后续可停止动作；已发生的副作用仍被报告。不可逆动作不得宣称自动补偿。

## AT06 Agent 边界
受控 Agent Loop 不得越过工具白名单、步数、深度、时间与预算。子任务和重试继承上游约束；外部黑盒 Agent 不得绕过可信工具边界。

## AT07 并发预算
两个 Worker 争夺最后预算额度时只有获准的请求发起付费动作；预算服务不可用时拒绝新增硬预算动作。真实费用未知时不得自动释放为零。

## AT08 产物权限
任务产生 artifact_id；另一租户不能读取；撤权后旧引用不得继续提供未授权内容；重试不静默覆盖产物。

## AT09 插件恢复粒度
确认 temporalio-langgraph 固定版本的 execute_in、Activity 重试、interrupt、streaming 去重和 Continue-As-New 行为。不得把图整体包为一次 Activity 后声称节点级恢复。

## AT10 版本演进
旧长任务在发布新能力/Worker 后按版本策略继续执行或显式迁移；旧历史重放不因节点重命名、序列化或工具变更失败。

## AT11 追踪与审计
API -> Workflow -> Agent -> Tool 关联 task/run/operation/attempt；断开 OTel exporter 不得造成业务收据或授权审计丢失。

## AT12 部署与可维护性
记录全部运行服务、数据库、备份恢复和依赖；可以清理并重建测试环境。记录新增能力涉及的文件和核心修改量。

## 验收规则
每项记录：前置条件、操作步骤、期望结果、实际结果、日志与持久化证据、失败归因、是否阻断下一阶段。
不得将文档声明或单次演示当作已通过验收。
