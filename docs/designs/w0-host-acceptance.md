# W0a / W0b 验收记录模板

适用于[正式 W0 设计](w0-host-design.md)。**前提状态：当前没有真实宿主。以下 16 个场景均为事前判据，正式执行数为 0。** 宿主就绪时登记实际构建、入口、测试主体/授权权威、业务服务与按号可查的收件端。只跑测试夹具、此前实验或仓库 CI 时，不填本表的实测结果。沿用[原需求验收表](../requirements/whole-product-acceptance-results.md)。各行是同一任务及其故障变体。运行时分别记录环境、输入、故障发生位置、预期、实际原始读数、判定、缺口归属。身份不全、服务未启动或无法观察所需收端，记“阻塞/试次无效”，修复后保留首份失败并重跑。

## 共用读数

每次运行留存宿主入口请求/身份决策、Task/Run/Workflow/Attempt、操作号/交付号、实际收端逐请求日志、**业务已提交次数、收件方接受次数**、产品状态与获准用户读回。对模型与外部工具另数实际传输、供方计量和产品预留/核销；对撤权另数首次交接顺序、受限字节/可兑换引用。幂等重复返回同一收据时，所有请求照数、效果只算一份。证据以因果屏障和持久记录定位，不用两机墙上时钟推断先后。载荷取样使用不同随机合成标记，保留经授权的阳性落点以排除漏检。一项硬性负例出现错误放行即失败，禁止用总体成功率抵消。

## W0b · 同链路的动态决策与恢复

| 场景、原需求 | 怎么触发 | 通过条件与主要证据 |
| --- | --- | --- |
| B1 动态选择与三入口 · FR-03/04/06/10–16/41，AC-02/04 | 同一个可异步返回的已发布 verify_item 能力分别由直接接口、固定工作流和 Agent 调用；每个入口各做有权及同权限拒绝对照。受控模型输入分别为证据齐备、仅缺一项、须先查目录再核事实。在上游能力目录登记无权、未发布及不相关候选，观察筛选后的模型请求。 | 确定性路径零模型。三类输入实测分别为 0、1、2 次工具调用；两工具例的第二调用须包含第一工具刚返回的随机引用。每个调用号有配对结果并有界终止。实收模型请求不含上述目录负例，直接/工作流/Agent 各自的有权样本到达业务端，无权样本零受限效果。给接入者一份带错误返回的契约示例。 |
| B2 模型已收、回复未知 · FR-06/09/28/29/37，AC-08 | 第一次模型已接收并记模拟费，回复/检查点尚未可用时杀 Worker，另一个 Worker 重入；并发触发同轮，另测任一轮（含下一轮）已认领但不能证实是否发送即崩溃，以及模型已返回工具请求、原消息及调用号尚未写入产品检查点时真杀。 | 已收样本同操作同轮物理到达 1、模拟费 1；产品未确认时保留原预留、工具和交付 0。未证实外发样本不得臆断到达/收费，不换轮次重购；待核可见。若原工具请求未持久化，只有从可信的该轮结果源读取同一响应、原调用号和完整消息并验证归属后才可按原请求继续；构造可查及不可查两个输入。前者只执行原工具一次，后者保持待核，工具/正式登记/交付均 0，不重发模型来重建一个看似相同的请求。按轮查账。 |
| B3 工具已生效、结果未记 · FR-06/28–31，AC-08/14 | 在工具端已生效但产品尚未记回执处强杀 Worker。先查未知，再开放权威查单，让两个进程同时取得同一回执；另测取消、撤权及错配/重复/乱序通知。AC-14 子例在异步工具已受理、提交响应超时且终局未知时取消父任务，捕获组件向子任务和可取消收端发送的取消请求及确认，再放出迟到终局。 | 合法样本按原工具调用和会话续一次。两轮一工具夹具的实际工具发送／效果／工具模拟费／模型请求／交付为 **1/1/1/2/1**。取消/撤权后为 **1/1/1/1/0**，可信迟到只核销一次；错配不能续轮，不能释放尚无依据的预留。父取消子例按可取消、无法中止或已生效分别记录请求、收端确停/仍在途及后续事实；新子任务、下一模型和交付均为 0。未知先持原父预算，迟到可信效果只更新账一次，不新授额度。另查应用状态和真实收端。 |
| B4 结果已记、下轮未发 · FR-28–30/32，AC-08/13 | 在工具结果已持久化、下一逻辑模型轮尚未认领时杀进程，再分别保留授权、撤权或令资料失效。 | 有权时读原检查点并按同一逻辑轮认领，新增模型接收和最终交付各 1；失权/失效时新增模型、工具、正式写入及交付各 0。恢复不再提交已生效工具。下一轮已认领而是否发送不明的窗口按 B2 待核，不能直接新增一次。 |
| B5 五个权限观察点 · FR-30/32–34，AC-06/13 | 已读受限数据后分别在持续运行和暂停恢复两条路径切换权限；对下一次读取、模型传输、工具传输、正式写入、受限交付逐个注入。与首次交接竞争，另做授权源失联及伪造身份负例。 | 每一必需观察点都有前后对照与实际接收方日志。撤权先行则受限字节或受保护实际效果 0。交接先行保留既有事实，仅允许本次不可撤回交接，其后失权动作 0；五个点都只计算撤权后的新增交接，已合法传出的字节/已提交的操作保留历史。权限未知拒绝。没有实际可控边界的该出口为阻塞。外部内容指示“越权取件”时同样为 0。 |
| B6 无进展、额度和模型故障 · FR-09/17/37，AC-07/16 | 用预先登记的合成额度与步数；同一父任务跨入口争用最后一个名额，新增轮次/子操作与取消同时到来。模型循环无进展、错误工具参数、不可兼容的模型配置分别注入。 | 每种限制能独立触发；停止原因、父账与预留明细一致，实际新增消耗不越额，未知不释放。有权正常样本能前进。模型或工具错误须可解释，不伪造返回；无已验兼容备用则停止。 |
| B7 上下文、追踪和权限视图 · FR-18/19/34/35，AC-12 | 插入独有无关历史及受限正文标记，压缩后重建进度；检查输入、引擎历史、日志/搜索属性、缓存和已配置索引、错误载荷、可读审计视图。两种主体各自查看。 | 无关历史不进入实际模型请求。进度从产品账、事实从获准业务记录读回；相关受控端有阳性。非授权视图及引擎引用域无正文/可兑换秘密；能由受控关联号还原权限、运行、版本、质量与终局。未配置的落点列不适用及依据。 |
| B8 在途升级、停接和回退 · FR-39/40，NFR-06/11，AC-11 | 用实际两个不同构建并存，旧任务等待时关闭旧版新受理；新版本读取兼容与不兼容的在途消息，然后回退。 | 能证明新请求走批准版本；旧任务同语义恢复，或在旧 Worker/隔离状态保留，绝无静默重解释与重复效果。版本、正确检查点、回退后收据均可查。仅改一个字段的同构建夹具不足以宣称真实发布通过。 |

**阶段归属与证据交回。** W0 覆盖原表 G01～G22 中这条任务触及的宿主职责；G23 只布置分类计量。G05 的完整协作模式、G10 长期记忆、G11 的真实知识发布/撤回、G17 的任意第三方执行器、G20/G23 混合负载与目标容量、G22 目标环境备份灾备、稳定后真正未知能力 AC-17 继续按原表相应阶段验收。W0 的合成目录、资料、预算争用及一次模型协议验证，不代替这些真实业务/运行验收。真实 SDK 可用可控模型取得可重复轨迹；若有已批准的隔离本地模型，可加一次独立协议读数，单列业务条件达成。未经批准的商业端点不作为 W0 前提。

W0a 全行、W0b 全行及同一最终版本 W0a 回归须各有正负样本和原始证据；每个约定注入点被实际命中才计有效试次。记录固定 SHA/依赖/服务版本、命令/退出码、运行人与时间、环境身份、PID/运行历史、权限变更位置、各收端逐笔事件和摘要。额外记录失败与无效试次；脱敏后随 W0 实施草稿归档。设计阶段的仓库 CI 只检查文档和既有回归。
