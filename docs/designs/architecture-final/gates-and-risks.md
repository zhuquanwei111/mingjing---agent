# 工程关口、风险与有限反转

最终架构裁决已收敛；项目方批准建设后从 W0a 开始。总控批准的设计和限定试验只对应本页列明的范围。原资源端、独立收件端和正式运营的签收仍要分别取得。

| 关口 | 负责人交付与签收条件 |
| --- | --- |
| 建设前 | 项目方批准公共宿主建设、中立资源、隔离网络和凭据控制范围。逐制品锁发行、镜像 digest、SBOM 与许可；确定数据与模型授权、供方查单/幂等期限及费用上界；业务方给出 G 最低分类负载及恢复目标。尚缺的合同只阻断其适用路径。 |
| W0a | 公共基座建最小宿主、可信测试身份、真实对象授撤权、按操作号查终局及本人按交付号查收/重开；用真实隔离收端逐场景留证。八个场景全部签收后进入 W0b。 |
| W0b | 在同一宿主加入真实动态选择、原模型回合/工具配对、进程恢复、取消和预算；八个场景逐一验，并在同一最终构建回归 W0a。旧 P1 适用判据通过并经确认后进入 G。 |
| G | 建成必要公共宿主和全部必需公共工程，逐项关联实际实现、配置、用例、失败/复测及收端证据。V01–V10 按适用范围签收；条件项未启用需验关闭。冻结稳定基座后由未参与原接入的人盲接未预置能力（AC-17），记录每项公共核心改动和理由。 |
| M | G 通过、首期业务实施方案独立评审并获准后，才开发“跟播—复盘—次日妆造预约”。实际业务资源方终核与本人交付重新取证。 |
| T | 另批真实数据、服务、岗位及有限试用范围。在真实岗位任务验证质量、权限、费用和可恢复性；跨期条目分别记录隔离证据和真实业务证据。 |
| P | 正式流量另批。以目标负载与账单、安全合规、回退、恢复演练、运维值守和业务签收决定放行。 |

W0a 沿用的场景为 A1 正常提交与读回、A2 输入、身份与目录、A3 重复受理与启动回执丢失、A4 业务质量正反例、A5 业务方最终核权、A6 已送达、回执丢失及下游失败、A7 正式业务已生效、回执丢失、A8 交付权限与再次打开。

W0b 沿用的场景为 B1 动态选择与三入口、B2 模型已收、回复未知、B3 工具已生效、结果未记、B4 结果已记、下轮未发、B5 五个权限观察点、B6 无进展、额度和模型故障、B7 上下文、追踪和权限视图、B8 在途升级、停接和回退。

保留[固定 W0 原判据和计数口径](https://github.com/zhuquanwei111/mingjing---agent/blob/8095d6f79e2e4e42fbdef03c8fdbfdf6b4785b35/docs/designs/w0-host-acceptance.md)。历史文档中的具名运行器按最终主体映射为唯一原生执行所有者；当时等待既有宿主的责任现由新公共基座承接。

## 何时必须停止受影响的实施

| F03 风险 | 现有证据与剩余条件 | 停止范围与替代边界 |
| --- | --- | --- |
| RISK01 动态恢复 | H1 顶层五项具证；嵌套、委派、并发、在途仍开放。 | 必要场景需重写 Agent Loop、检查点或通用重放时，停止并报主体局部复核。 |
| RISK02 等待与续流 | 在所选运行方式实测租约、pending、裁剪、重投、跨客户端续流和定时。 | 单 Run 单所有者；原生已够即取消 EXEC-3，转换器不合格才限用原生 TS SDK。 |
| RISK03 身份与真实权威 | 后端纳入新建宿主；旧执行者、五出口和各真实资源还须验。 | 无法排序或权威失联时关闭对应出口，修资源接口或隔离机制。 |
| RISK04 管理面 | 免费 Studio、原生后台和 React-admin 缺页须在生产模式验证权限和操作。 | 必要功能依赖付费或须重造整套后台，报受影响管理选择。 |
| RISK05 外部未知、硬预算 | B03 本地事务已裁决；真实最坏费用、幂等时限、按号查终局和真实核销待验。 | 不可查时保留待核和预留；必要动作长期无合格合同则另定该供方或能力。 |
| RISK06 ETL 与对象 | 真连接器、错误行、正式发布、S3 原生兼容和 filer 恢复均须实测。 | 只替换不合格的连接器、存储或具体接线。 |
| RISK07 知识撤回及归账 | H1 残文、错账保留；H2 证明关闭 A/活动 B 下签名批次与干净重建。并行活动批次、全部来源和出口、质量及成本待 G。 | 权限近似按人复制、重建成本超批准上界、必要知识质量不合格或须大面积 fork，停止并仅提 A07 局部反转。 |
| RISK08 传递依赖与许可 | MinerU 商用条件、权重、ParadeDB、队列兼容及实际镜像分别审查。 | 制品不合格只替换该依赖，保留必要功能并重验。 |
| RISK09 模型合同 | 真实地区、快照、工具协议、查费用上界和外发授权待确认。 | 不静默切模型或重复计费；替换须获准并验。 |
| RISK10 可观测性 | 原生 PG 观测及免费查询待实测；真实审计有独立证据。 | 如不满足只复核受支持的观测存储，避免双写成第二事实权威。 |
| RISK11 部署容量与灾备 | 混合负载、两版本回退和跨权威恢复在独立目标环境取证。 | 未达 G 不开 M；真实 T/P 目标未达不放相应流量。 |
| RISK12 自研维护面 | 记录 C1–C6 实际改动、运维责任及可复用部分，尤其 C1–C4 的公共工程。 | 需长期重写成熟运行、知识、治理或管理核心即停，按影响范围报总控。 |
